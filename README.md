- **P3 - More Loops**

- **P4.2 - Sequence extension**

- **Controls**


## Puntos Clave
- Código limpio y pensado para entender el algoritmo.
- Soluciones que pasan los **Test Cases** del Jutge.
- Estilo **C++11/C++17** standard.
- Nivel **principiante**.

---

>[!TIP]
> **Para estudiantes:**
>
> Mi recomendación es que **no copies el código tal cual**. La gracia de PRO1 es "pelearse" con el problema hasta que sale.
> 
> Utiliza estas soluciones solo si estás **muy atascado** y necesitas ver un enfoque diferente para desbloquearte. Lo más importante no es tener el tic verde ✅, sino **entender la lógica** que hay detrás para poder aplicarla tú mismo. Ánimo con la asignatura!
